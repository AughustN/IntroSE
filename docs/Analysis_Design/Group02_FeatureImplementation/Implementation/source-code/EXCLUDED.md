# What was excluded from this source-code copy, and why

PA4 §E asks for "the complete source code (exclude `node_modules`, `venv`, build artifacts, and other
generated directories)". This copy is the full working tree of the repository at submission time with
only the following removed. Everything else — every source file, every migration, every test, every
config file, and all documentation — is present.

| Removed | Reason |
| --- | --- |
| `node_modules/` | Explicitly excluded by PA4 §E. Restored with `npm install`; `package.json` and `package-lock.json` are both included, so the install is reproducible. |
| `dist/` | Build artifact — explicitly excluded by PA4 §E. Regenerated with `npm run build`. |
| `coverage/` | Generated by `npm run test:coverage`. |
| `.git/` | Version-control metadata, not source. The commit history is supplied separately as the Git log required by the Submission Guidelines. |
| `.env` | **Live secrets** — database URLs, `JWT_SECRET`, `AUTH_EVENT_HASH_KEY`, VNPay and Resend credentials. Never distributed. `.env.example` **is** included and documents every variable with instructions. |
| `.env.bak` | Same reason: an older copy of the live secrets. |
| `uploads/` | Runtime user uploads (avatars and floor plans, ADR-0004), written by the running server. Not source; may contain personal data. |
| `.claude/`, `.agents/` | Local AI-assistant configuration, machine-specific and git-ignored. The AI usage declaration is a separate PA4 §F deliverable. |
| `.codegraph/` | Local tooling cache. |
| `VNM Sans (3 fonts)/` | Original font sources (`.otf`/`.ttf`) kept outside the build. The `.woff2` the app actually loads **is** included, at `src/fonts/`. |
| `PA4-2026.pdf` | The assignment brief itself. |
| `PA4-Group02/` | This submission bundle — copying it into itself would recurse. |
| `/.specify` (repo-root junction) | A Windows directory junction pointing at `src/.specify`, created so the tooling resolves from the drive root. Machine-local and not a real directory. **The real thing, `src/.specify/`, is included.** |

## Deliberately kept, in case it looks unexpected

- **`.env.example`** — no live credentials, only placeholders and the documentation of each variable.
- **`docs/`** — the project's documentation tree (vision document, use-case specification, database schema, ADRs, deployment notes, management documents). Part of the repository and needed to check that the architecture matches the code.
- **`src/specs/`** and **`src/.specify/`** — the Spec Kit artifacts, in the location Spec Kit uses. They are also copied to `../SpecKit/` for convenience.
- **`log.md`** — the project work log.
- **`server/src/db/migrations/*.sql`** — the database schema. The repository's `.gitignore` deliberately anchors its `*.sql` rule to the root so these are never ignored.
